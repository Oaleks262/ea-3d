# Elizaveta Antoniuk - 3D Animator & Motion Designer Portfolio

Professional portfolio website showcasing 3D animation and motion design work.

## Features

- 🎨 Modern, responsive design with dark theme
- 🎬 Project showcase with video previews
- 📧 Contact form with email notifications
- 🔐 Admin panel for content management
- 🖼️ Automatic image conversion to WebP
- 🎥 Automatic video conversion to WebM
- 🌈 Customizable color scheme
- 📱 Fully responsive on all devices

## Tech Stack

### Frontend
- React 18 + Vite
- Framer Motion (animations)
- SCSS (styling)
- React Router (navigation)
- Axios (API calls)

### Backend
- Node.js + Express
- Multer (file uploads)
- Sharp (image processing)
- FFmpeg (video processing)
- Nodemailer (email)
- bcrypt (authentication)
- JWT (sessions)
